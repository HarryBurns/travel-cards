# Ну долго ещё?

Шуточная онлайн-игра про неопытных туристов: посмотрели достопримечательность — захотелось есть,
поели — захотелось пить, попили — срочно ищем туалет. И по кругу.

Без регистрации: заходишь на страницу, вводишь имя, видишь лобби. От 2 до 6 игроков.

## Правила

| На карту | можно положить |
|---|---|
| 📸 Достопримечательность | 🍜 Еду или 🧋 Напиток |
| 🍜 Еда | 🧋 Напиток или 🚽 Туалет |
| 🧋 Напиток | 🚽 Туалет |
| 🚽 Туалет | 📸 Достопримечательность |
| ⭐ Джокер | что угодно (и сам джокер кладётся на что угодно) |

- Каждому раздаётся по 4 карты. Случайный игрок начинает: его случайная карта ложится на стол.
- Ходим по одной карте. Нечем ходить — тянешь из колоды, пока не придёт подходящая.
- Когда колода кончается, сброс перемешивается и становится новой колодой.
- Первый, кто остался без карт, улетает домой — партия окончена.

Карты с эффектами (обычные карты своего типа, подчиняются тому же циклу):

| | Эффект |
|---|---|
| ⏭️ Пропуск хода | следующий игрок пропускает ход |
| 🔄 Разворот | ход идёт в обратную сторону (вдвоём — как пропуск хода соперника) |
| ➕ Плюс две | следующий берёт 2 карты и пропускает ход |
| ⚡ Ещё ход | сыгравший ходит ещё раз |
| 🔀 Обмен | поменяться всеми картами с любым игроком |

Если игрок отвалился, его ждут минуту, после чего за него ходит автомат (и продолжает ходить,
пока игрок не вернётся). Вернуться можно в любой момент — достаточно снова открыть страницу.

## Как это устроено

Чистая статика для GitHub Pages, без сборки. Сервера нет: состояние лежит в Firebase Realtime
Database, каждый ход — транзакция, которую выполняет браузер ходящего игрока.

```
index.html
css/style.css
js/app.js        корень: имя → лобби → комната → игра
js/game.js       игровой стол
js/ui.js         карта, модальные окна, правила
js/rules.js      правила игры — чистые функции без DOM и сети
js/net.js        вся работа с Firebase
js/cards.js      колода и фразы-реакции
js/config.js     адрес базы и таймауты
js/credits.js    авторы фотографий (генерируется)
js/review.js     страница проверки картинок (review.html)
js/vendor/       Firebase SDK и Preact, собранные в один файл каждый
img/cards/       картинки карт, 480×360 webp
tools/           подбор картинок
test/            тесты правил
```

### Запуск у себя

```bash
python3 -m http.server 8080
```

и открыть http://localhost:8080. Параметр `?ns=что-нибудь` включает отдельную «песочницу» в базе,
чтобы тестовые игры не попадали в общее лобби.

### Тесты

```bash
npm test
```

### GitHub Pages

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.

### Правила доступа Firebase

В консоли Firebase: Realtime Database → Rules — вставить содержимое `database.rules.json`.
Тестовый режим, в котором база создаётся по умолчанию, перестаёт работать через 30 дней.

Авторизации в игре нет, поэтому правила лишь ограничивают, куда можно писать. Технически
подкованный игрок может подсмотреть чужие карты или испортить партию — для игры с друзьями
это приемлемо, для чего-то серьёзного нужна авторизация и серверная проверка ходов.

## Как добавить карту

1. Добавить строку в `js/cards.js` (id — латиницей, уникальный).
2. Добавить поисковый запрос для картинки в `tools/image-queries.json`.
3. Подобрать картинку:

```bash
python3 tools/images.py search <id>
python3 tools/images.py list <id>     # посмотреть кандидатов
python3 tools/images.py fetch <id>
python3 tools/images.py sheet         # контактный лист в .imgwork/sheets
python3 tools/images.py final <id>
```

Чтобы взять не первого кандидата, укажи файл в `tools/image-picks.json`:
`{"<id>": {"file": "File:Название.jpg"}}`. Карта без картинки тоже работает — вместо фото
будет значок типа.

### Проверка картинок

`review.html` — служебная страница: все картинки колоды на одном экране. Картинку можно пометить
плохой, оставить комментарий или выбрать замену из других найденных вариантов. Пометки сохраняются
в базе по пути `test/review`. Список вариантов лежит в `review/candidates.json` и обновляется
командой `python3 tools/images.py export`.

Баланс: достопримечательностей, туалетов и «еды + напитков» должно быть примерно поровну,
иначе цикл начнёт стопориться. Размер стартовой руки — `HAND_SIZE` в `js/rules.js`.
